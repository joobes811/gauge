# Gauge

The built web app for Gauge, a personal drink tracker that estimates blood alcohol and helps cut back on drinking days.

Open it at **https://joobes811.github.io/gauge/** in Chrome on Android, then choose **Install app**.

- Everything you log stays on your own phone. This site only serves the app; it never receives your data.
- An estimate, not a breathalyser. Real levels can sit 30% either side. Not for deciding whether you're OK to drive, including the next morning.

The `gh-pages` branch is generated by a deploy script; the source lives elsewhere.
